All JSON files (calculation outputs and observational data) live here as of v3.1.2-final.


## Total: 91 files

- **calculation outputs**: ~79 files (in `json/calculations/`)
- **observational data**: ~12 files (in `json/data/`)

## Why separate calculations from data?

- **calculations/**: Machine-readable results from SIDC analysis scripts. Re-generated by running `python3 calculations/<script>.py`. Don't edit by hand.
- **data/**: Observational data from external surveys (SPARC, Tian+ 2024, UDG). Used as INPUT to calculations. Don't modify.
