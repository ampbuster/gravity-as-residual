============================================================
WHAT IS F-THEORY?
============================================================

F-theory (Vafa 1996):
  - 'F' for 'Father' (Vafa's joke)
  - A geometric formulation of Type IIB string theory
  - Makes Type IIB's SL(2,Z) symmetry geometric

The key idea:
  - Type IIB has axio-dilaton τ = C₀ + i e^(-φ)
  - τ transforms under SL(2,Z)
  - F-theory identifies τ with the COMPLEX STRUCTURE of an elliptic curve T²
  - This 'T² fiber' is a 2D auxiliary dimension
  - The T² fibration over a 10D base gives '12D'

Reference: Vafa, 'Evidence for F-theory', Nucl. Phys. B 469 (1996)

============================================================
THE 12D STRUCTURE
============================================================

F-theory is '12-dimensional' in a specific sense:

  10D = the actual spacetime (Type IIB base)
  + 2D = the elliptic fiber T² (auxiliary)
  = 12D total geometric structure

The 2D T² fiber is NOT a real extra dimension.
It's a geometric encoding of Type IIB's axio-dilaton.

But it's a USEFUL way to think about non-perturbative effects:
  - D7-branes in Type IIB = loci where T² degenerates
  - O7-planes = specific T² degenerations
  - (p,q)-strings = (p,q)-cycles on T²
  - SL(2,Z) of Type IIB = modular group of T²
