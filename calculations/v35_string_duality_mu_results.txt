Framework: M_s = M_Pl,2D = 3000 GeV (low string scale)

================================================================================
STEP 1: Modular parameter b
================================================================================

Closed string worldsheet is parameterized by complex τ = τ₁ + i τ₂.
Thermal partition function uses b = √(α' T) for temperature T:

  Z(b) = Σ d_n e^{-b² n / α'}

Modular invariance: Z(b) = Z(1/(2b)) [closed string only]
Note the factor of 2 difference from open string (where b → 1/b).

================================================================================
STEP 2: Self-dual point of b ↔ 1/(2b)
================================================================================

Self-dual condition: b = 1/(2b)
                    → 2b² = 1
                    → b² = 1/2
                    → b = 1/√2 = 0.707107

At this point, Z(b) = Z(b). The thermal partition function is
invariant — this is the 'minimum temperature' (Kogan 1990).

================================================================================
STEP 3: T_H from self-dual b
================================================================================

Per Chaudhuri 2001 PRL 86, 1943: T_H = M_s/(2π)
T_H = 3000/(2π) = 4.7746e+02 GeV
    = 0.4775 TeV

Alternative convention: T_H = 1/(4π² α') = M_s²/(4π²)
T_H (alt) = 2.2797e+05 GeV
        = 2.2797e+05 × GeV = 75.9909 M_s

================================================================================
STEP 4: 2D BH μ from T_H
================================================================================

μ = (2π T_H)² = (2π × 4.7746e+02)²
    = (3.0000e+03)² = 9.0000e+06 GeV²

This matches framework's μ = M_Pl,2D² = (3000)² = 9.0000e+06 GeV² ✓

================================================================================
WHY b → 1/(2b) HAS A FACTOR OF 2:
================================================================================

Closed string: worldsheet has both left and right movers
Modular parameter b appears in TWO factors (left and right):
  b_eff = b_L + b_R = 2b  (when left and right are symmetric)

Thermal duality acts on b_eff: b_eff → 1/b_eff
  2b → 1/(2b)
  b → 1/(2b)

Open string: only one set of movers, no factor of 2
  b → 1/b (no factor of 2)

So the '2' in 1/(2b) is from left-right symmetry of closed string.

================================================================================
PHYSICAL MEANING OF SELF-DUAL POINT:
================================================================================

At T = T_H:
  - String partition function is invariant under b ↔ 1/(2b)
  - This is a MAXIMUM stable temperature (heating more = phase transition)
  - Hagedorn phase transition to higher-temperature phase
  - In the IIA-IIB duality: gas of IIA strings → gas of IIB strings

Chaudhuri 2005 result:
  'A gas of free heterotic strings undergoes a Kosterlitz-Thouless
   duality transition with positive free energy and positive specific
   heat but vanishing internal energy at the self-dual temperature.'

So T_H is a UNIQUE temperature where string thermodynamics has
special behavior. This is the 'minimum/maximum temperature' that
gives μ = M_Pl,2D².
